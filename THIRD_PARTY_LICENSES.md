# Third-party components & licenses

This project builds on and/or references the following third-party works.

None of them is bundled inside the repository; binaries are downloaded at build time
or referenced as external tools. Their notices are listed for compliance.

## LibreHardwareMonitorLib (runtime sensor library)

- Project: https://github.com/LibreHardwareMonitor/LibreHardwareMonitor
- License: **Mozilla Public License 2.0 (MPL-2.0)**
- Used by: `studio` (GUI data engine) and `monitor` (legacy host tool)
- The library DLL is **not committed** to this repository. `studio/build.bat` and
  `monitor/build_monitor.bat` download the official release archive when `lib\` is missing.
- MPL-2.0 text: https://mozilla.org/MPL/2.0/

## Adafruit GFX font bitmap (5x7 dot-matrix font)

- Source: `Adafruit-GFX-Library` `glcdfont.c`
  https://github.com/adafruit/Adafruit-GFX-Library
- License: **BSD-3-Clause**, Copyright (c) Adafruit Industries
- Used by: `studio/fontdata.cs` (generated by `studio/fontgen.py`), the classic fixed-space
  bitmap font shown on the simulated and real LCD panels.

## HWiNFO (optional data source)

- Project: https://www.hwinfo.com
- Status: **proprietary freeware** (personal use). The `HWiNFO` product is **not**
  bundled, downloaded, or redistributed by this project in any form.
- This project only reads the **public shared-memory interface** published by HWiNFO
  when the user has installed it and enabled "Shared Memory Support" themselves.
  See https://www.hwinfo.com/license/ for HWiNFO's own terms.

## PawnIO (optional driver, referenced only)

- Project: https://pawnio.eu / https://github.com/namazso/PawnIO.Setup
- Not bundled. Mentioned in the guide UI as an optional prerequisite for AMD CPU
  temperature access with LibreHardwareMonitor.

## 合宙 CORE-ESP32-C3 PinOut 脚位图 (docs/pinout_board.png)

- Source: **合宙 (AirM2M) LuatOS 官方文档** — https://wiki.luatos.com
  ("合宙ESP32-C3开发板PinOut示意图 V4.22110201")
- Status: **vendor documentation image, copyright 合宙 (AirM2M)**. It is **not** open-source
  licensed material.
- Usage here: `docs/pinout_board.png` is a **crop** of that diagram (board photo + pin numbers
  + silk labels), used **solely as the base layer of the wiring illustration**
  `docs/wiring_board.svg` / `docs/wiring_board.png`, to make the pinout unmistakable for users.
- Attribution is printed inside the illustration itself and in README / HARDWARE docs.
- If you redistribute this repository commercially, replace this image with your own drawing —
  the pure-vector alternative `docs/wiring.svg` (self-drawn, no third-party content) is provided
  for exactly that purpose.

## Hardware documentation

Datasheets/schematics for the dev board, LCD and adapter are **not** included in this
